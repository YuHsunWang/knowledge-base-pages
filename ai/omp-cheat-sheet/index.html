    AI Agents Coding Agent OMP

    OMP 指令速查表（本機）¶

    摘要¶

    在私人筆電（OMP Host）上用的指令收成一頁。omp ... 在終端機執行；/... 在筆電上的 OMP 裡輸入。從其他電腦或手機的瀏覽器操作，請看 OMP 速查表（網頁）。

    資料基準：2026-09。OMP 版本會變，實際可用選項以 omp --help、omp config list、omp models 為準。

    安裝與初始化¶

    # macOS / Linux
curl -fsSL https://omp.sh/install | sh

    # Windows PowerShell
irm https://omp.sh/install.ps1 | iex
    目的 指令
    安裝（Homebrew） brew install can1357/tap/omp
    確認版本 omp --version
    查看 CLI 說明 omp --help
    第一次初始化 omp setup

    Provider 與模型¶

    目的 指令
    登入 Provider（選單） omp login
    登入指定 Provider omp login anthropic / omp login openai
    列出可用模型 omp models
    搜尋模型 omp models find claude / gpt / gemini
    列出自訂 Provider 的模型 omp models my-provider
    Session 內切換模型 /model
    啟動時指定模型 omp --model <provider>/<model>
    啟動時指定角色 omp --model slow 或 omp --model @slow
    設定思考等級 omp --thinking high

    思考等級：off · minimal · low · medium · high · xhigh（是否支援看模型）。

    模型角色：default 日常 · smol 快又便宜 · slow 深度推理 · plan 規劃 · vision 圖片 · advisor 第二意見 · task Subagent · designer 設計。

    啟動與 Session¶

    目的 指令
    在專案內啟動 cd ~/Projects/my-project && omp
    繼續最近的 Session omp --continue 或 omp -c
    從歷史挑一個 Session omp --resume
    繼續指定 Session omp --resume <session-id>
    從某個 Session 分支 omp --fork <session>

    開啟 Collab 遠端控制¶

    在筆電上的 OMP 裡輸入：

    目的 指令
    開啟完整控制 /collab
    開啟唯讀分享 /collab view
    查看狀態 /collab status
    停止 Collab /collab stop

    在終端機執行：

    目的 指令
    列出執行中的 Host omp collab list
    取得連結 omp collab link <instanceId>
    取得唯讀連結 omp collab link <instanceId> --view
    從另一個終端機加入 omp join "..."

    開好之後，其他電腦或手機怎麼加入，見 OMP 速查表（網頁）。

    Collab URL 等於密碼

    完整控制的 URL 可以送 Prompt，也能讓 Host 執行工具。不要貼到公開頻道、Issue、Repository 或群組信。只想給人看畫面時，用 /collab view。

    設定¶

    目的 指令
    列出全部設定 omp config list
    查一個設定值 omp config get tools.approvalMode
    修改設定 omp config set <key> <value>
    查看設定檔路徑 omp config path
    啟動時自動開完整控制 omp config set collab.autoStart control
    啟動時自動開唯讀 omp config set collab.autoStart view
    關閉自動 Collab omp config set collab.autoStart off
    設定顯示名稱 omp config set collab.displayName Shane-Laptop

    設定檔位置：

    檔案 用途
    ~/.omp/agent/config.yml 全域設定
    ~/.omp/agent/models.yml 自訂模型 / Provider
    your-project/.omp/config.yml 專案設定
    ~/.omp/agent/extensions/ Extension
    AGENTS.md（repo 根目錄） 專案規則

    權限（Approval Mode）¶

    Mode Read Write Shell / Exec
    always-ask 自動 問 問
    write 自動 自動 問
    yolo 自動 自動 自動

    遠端使用建議從 write 開始：

    omp config set tools.approvalMode write

    手機通知（ntfy）¶

    export OMP_NTFY_TOPIC="your-private-topic"
curl -d "OMP task completed" https://ntfy.sh/YOUR_PRIVATE_TOPIC

    Topic 名稱也是 Secret

    知道 Topic 的人都能收到你的通知。用環境變數，不要寫進 Repository。

    第一次設定：10 步¶

    curl -fsSL https://omp.sh/install | sh           # 1. 安裝
omp setup                                         # 2. 初始化
omp login                                         # 3. 登入 Provider
omp models                                        # 4. 確認模型
omp config set tools.approvalMode write           # 5. 權限
omp config set collab.autoStart control           # 6. 自動 Collab
omp config set collab.displayName Shane-Laptop    # 7. 顯示名稱
cd ~/Projects/your-project && omp                 # 8. 進專案啟動

    9. 在 OMP 輸入 /collab，用手機掃 QR Code。 10. 確認手機能送 Prompt、Shell 需要批准、工具在筆電執行、筆電不會睡眠。
